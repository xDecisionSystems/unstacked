Permissions

Home page

Publishing the Home page lets anyone reach it without signing in. An unauthenticated visitor who follows a link to a page they cannot read is sent to Home when it is public, or to the login page otherwise.

Books

Set each group’s exact book access: dash for no access, glasses for read, and pencil for read & write. Click an icon at the top of a column to apply it to every book. Icons next to a book set the default for newly created groups.

Featured page overrides

Pages normally inherit their book. A page featured on the home screen may have an exact override here.

All path grants

More-specific grants take precedence.

API tokens

Tokens are short-lived, shown once, and revoking invalidates every token for that account.



Branding
Change the name and optional logo shown in the top header. Upload a PNG, JPEG, GIF, or WebP logo.


Home page
Home's copy and widget layout are now edited on the Home page itself, not here -- open Home and use its Edit button if you have write access to it.
Reset to starter content
This discards the Home page's current body and widget layout and replaces them with the original starter content. This cannot be undone.


GitHub repository
Each content edit is committed to the content repository and automatically synchronized to its main branch. A private repository is required only when any group has restricted read access.
 


Appearance
